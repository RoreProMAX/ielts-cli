# IELTS CLI Portable 3.3.0 部署指南

这是一份给新电脑使用者和朋友的单文件 ZIP 部署说明。交付包名：`IELTS-CLI-Portable-3.3.0.zip`。

## 先看结论

- 解压后，ZIP 根目录应直接包含 `launcher.py`、`start.sh`、`start.command`、`start.bat`；不要再进入第二层同名目录。
- 包内含程序和 5 本词库，不含 Python、`ffplay`、网络音频缓存或学习记录。
- V3 默认只使用本机系统用户目录；首次运行默认不导入旧进度。
- `--portable` 把程序数据写入 ZIP 解压目录内的 `user-data/versions/3.3.0/`，发音缓存写入 `user-data/cache/ielts-cli/audio/`。
- 发音需要联网下载音频，并且本机 PATH 中有 `ffplay`。没有它仍可使用文字练习，只有播放失败。
- Python 和播放组件需要用户自行准备。

## 系统要求和外部依赖

| 平台 | 必需 | 发音播放 | 后台提醒 |
|---|---|---|---|
| Linux | Python 3.10+（含标准库 `curses`） | FFmpeg 包中的 `ffplay` | 可选 `systemd --user` + `notify-send` |
| macOS | Python 3.10+（含标准库 `curses`） | FFmpeg 的 `ffplay` | 使用程序内提醒 |
| Windows | Python 3.10+ 与 `windows-curses` | Windows FFmpeg 构建中的 `ffplay.exe` | 使用程序内提醒 |

建议使用 64 位 Python。Windows 原生终端还需要安装与当前 Python 相匹配的 `windows-curses` wheel。

### Windows：Python 和 windows-curses

1. 从 [Python 官方 Windows 下载页](https://www.python.org/downloads/windows/) 安装 Python 3.10 或更高版本。安装器中勾选 “Add Python to PATH”（若界面提供）。也可使用 Python 官方安装管理器；官方文档给出的 WinGet 命令是：

   ```powershell
   winget install 9NQ7512CXL7T
   ```

2. 打开新的 PowerShell，确认解释器：

   ```powershell
   py -3 --version
   ```

   启动脚本优先使用 `py -3`。若电脑只提供 `python`，把安装命令改为 `python -m pip`，脚本会自动使用它。

3. 在 ZIP 根目录执行 Windows 依赖安装：

   ```powershell
   py -3 -m pip install -r requirements-windows.txt
   ```

   `requirements-windows.txt` 固定 `windows-curses==2.4.2`。当前 PyPI 发布页列出 CPython 3.10–3.14 的 Windows x86 与 x86-64 wheels；本包的 Python 要求是 3.10+，使用 CPython 并选择与解释器架构匹配的 wheel。来源：[PyPI windows-curses](https://pypi.org/project/windows-curses/)。

### FFmpeg / ffplay

程序只调用 `ffplay`，不需要单独的 Python 音频包。请安装含 `ffplay` 的 FFmpeg 构建，并确保命令能在新终端中找到。

- Windows：从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)进入 Windows builds（官方页列出 gyan.dev 和 BtbN），下载适合系统的构建，解压后将包含 `ffplay.exe` 的 `bin` 目录加入 PATH。然后在 PowerShell 检查：

  ```powershell
  ffplay -version
  ```

- Ubuntu/Debian：使用系统包管理器（Ubuntu 包页面列出 `ffmpeg` 包）：

  ```bash
  sudo apt update
  sudo apt install ffmpeg
  ffplay -version
  ```

  [Ubuntu ffmpeg 包信息](https://packages.ubuntu.com/ffmpeg)；其他发行版请按发行版的软件源安装。FFmpeg 官方下载页也列出了 Debian、Ubuntu、Fedora 等包入口。

- macOS（已安装 Homebrew 时）：

  ```bash
  brew install ffmpeg
  ffplay -version
  ```

  [Homebrew 官方 ffmpeg 公式](https://formulae.brew.sh/formula/ffmpeg)明确列出 `brew install ffmpeg`，并将 `ffplay` 列为安装的二进制工具之一。尚未安装 Homebrew 时，请先按 [Homebrew 官方安装说明](https://brew.sh/)操作。

若 `ffplay -version` 成功但程序仍提示找不到它，请重开终端；图形启动器不会自动继承安装前已经打开的终端环境。

## 下载、解压和第一次启动

### Linux

先安装 Python 和解压工具：

```bash
sudo apt update
sudo apt install python3 python3-venv unzip
```

将 ZIP 放在任意目录。路径可以包含空格和中文，但命令中的路径必须用引号包住：

```bash
mkdir -p "$HOME/Apps/IELTS CLI"
unzip "IELTS-CLI-Portable-3.3.0.zip" -d "$HOME/Apps/IELTS CLI"
cd "$HOME/Apps/IELTS CLI"
chmod +x start.sh
./start.sh
```

若启动脚本不可执行，也可以直接运行：

```bash
python3 launcher.py --app-version 3
```

### macOS

已安装 Homebrew 时先安装 Python：

```bash
brew install python
```

在 Finder 中双击 `start.command`。首次运行若 macOS 阻止脚本，可右键选择“打开”，或在终端执行：

```bash
cd "/Users/你的用户名/Applications/IELTS CLI"
chmod +x start.command
./start.command
```

路径中的中文、空格和括号均可保留；不要删掉引号。也可以直接执行 `python3 launcher.py --app-version 3`。

### Windows

在资源管理器中解压 ZIP，双击 `start.bat`。若需要查看错误信息，打开 PowerShell 后：

```powershell
Set-Location "C:\Users\你的用户名\Desktop\IELTS CLI"
python launcher.py --app-version 3
```

路径中的空格和中文不需要改名；PowerShell 的路径参数请保留双引号。不要直接双击 `launcher.py`，因为窗口可能在错误出现后立即关闭。

## 入口和版本选择

默认启动 V3：

```text
Linux/macOS: ./start.sh              （或 ./start.command）
Windows:     start.bat
通用:        python launcher.py --app-version 3
```

统一入口支持三个应用版本。版本数据彼此隔离：

```bash
python3 launcher.py --app-version 1
python3 launcher.py --app-version 2
python3 launcher.py --app-version 3
```

启动前检查环境和包内容：

```bash
python3 launcher.py --doctor
python3 launcher.py --verify
```

需要明确使用包内数据目录时：

```bash
python3 launcher.py --app-version 3 --portable
```

单独执行 `--verify` 可检查包内容。V3 的详细学习选项以包内程序显示的 `--help` 为准；入口透传 `--stats`、`--list-dictionaries`、`--review` 等参数。

## 数据位置、迁移和分享

### 默认模式

默认模式把当前版本数据放在当前系统用户目录的以下位置：

```text
Linux:  ${XDG_DATA_HOME:-~/.local/share}/ielts-cli-portable/versions/3.3.0/
macOS:  ~/Library/Application Support/IELTS-CLI-Portable/versions/3.3.0/
Windows: %LOCALAPPDATA%\IELTS-CLI-Portable\versions\3.3.0\
```

其中包含学习进度、设置、复习数据库等运行数据。不同版本目录分开，升级或切换版本不会自动双向同步。`--doctor` 会显示当前平台解析出的实际路径，且不创建或修改数据文件。

默认首次运行不导入旧进度。升级自己的旧便携包时，先退出旧程序，在新版解压目录中执行：

```bash
mkdir -p "新包/user-data/versions"
cp -a "旧包/user-data/versions/3.2.0" "新包/user-data/versions/3.3.0"
```

Windows 可在资源管理器中将旧包的 `user-data\versions\3.2.0` 复制为新版的 `user-data\versions\3.3.0`。保留旧包和源目录。正常模式也请复制到 3.3.0 新目录后运行，以保留旧版原数据。

### 自己携带进度的便携模式

在解压目录执行（Linux/macOS）：

```bash
python3 launcher.py --app-version 3 --portable
```

Windows 使用：

```powershell
python launcher.py --app-version 3 --portable
```

数据写入包内 `user-data/versions/3.3.0/`，发音缓存写入 `user-data/cache/ielts-cli/audio/`。整个解压目录可以复制到 U 盘或另一台电脑；目标电脑仍须有匹配的 Python、Windows 的 `windows-curses`（若适用）和 `ffplay`。复制前退出程序，复制后先运行 `--doctor` 和 `--verify`。

### 发给朋友的清洁副本

请从原始、未启动过的 `IELTS-CLI-Portable-3.3.0.zip` 发送。压缩内容只保留程序、词库、启动脚本、来源和校验文件；自己的 `user-data/`、`cache/` 和日志不放入分享包。可解压到临时目录检查根目录和 `user-data/`，再运行 `--verify`。

## 网络、音频和离线边界

词库和终端界面可在无网络时运行。发音第一次播放某个词时需要联网下载音频，成功缓存后可离线重播；ZIP 本身不含音频缓存。

没有网络时，程序给出播放失败提示，文字练习仍可继续。没有 `ffplay` 时，`--doctor` 报告缺失；安装后重新打开终端再检查。

## V3.3 版本更新

自动更新从 V3.3.0 开始提供。V3.2.0 及更早用户需先手动安装/切换到 V3.3.0 一次，旧版不会自行更新。V3.3 启动时默认在后台检查 `RoreProMAX/ielts-cli` 的公开 stable Release。检查仅在程序运行时进行，不安装 systemd，不自动下载、安装或重启，也不打断当前学习。Esc 菜单 10“版本与更新”及学习计划中的“启动时检查稳定版本”可查看或关闭该开关；菜单内部选项编号随状态动态显示；无网络或 GitHub 限流时继续正常学习。

更新页先让用户选择“下载并校验 vX”；下载完成后再选择“保存进度并重启到 vX”或“下次启动使用 vX”。选择“暂不更新，继续当前练习”只收起本次会话提示。更新器只接受 stable Release，并校验官方 asset 的 SHA-256 与 ZIP 清单；文件下载到当前进度目录 `updates/releases/<version>`。自动更新沿用当前同一进度目录，区别于手工复制到新版本目录的跨版本迁移。启用前先把 JSON 与 SQLite 备份到 `updates/backups`，`update_settings.json` 保存开关，`updates/active.json` 保存激活指针。旧程序和旧 ZIP 保留；`--no-update` 仅本次使用原入口版本并跳过检查，不修改用户设置。更新不上传个人词库或进度，也不升级 Python、`windows-curses`、`ffplay` 或词库。

命令行配置：`--configure --auto-update-check on|off`；只读查看：`--update-status`；本次跳过：`--no-update`。测试隔离网络时设置 `IELTS_DISABLE_UPDATE_CHECK=1`。

## Linux 后台提醒

后台提醒适用于 Linux 的 `systemd --user` 会话，并依赖 `notify-send`。Ubuntu/Debian 可运行 `sudo apt install libnotify-bin` 安装通知工具。本包使用独立的 `ielts-cli-portable-review.timer`，默认不启用；Linux 上执行：

```bash
python3 launcher.py --app-version 3 --reminders enable --reminder-minutes 30
python3 launcher.py --app-version 3 --reminders status
python3 launcher.py --app-version 3 --reminders disable
```

提醒在用户登录会话中运行；程序正在运行、没有到期词或提醒被暂缓时不会弹出通知。macOS 和 Windows 使用程序内提醒设置。移动文件夹前在旧位置执行 `--reminders disable`，移动完成后在新位置重新执行 `--reminders enable`。使用便携进度时，开启命令也须加 `--portable`。

## 故障排查

1. **窗口一闪而过**：在终端中进入解压目录后运行 `python launcher.py --doctor`；Windows 使用 PowerShell，Linux/macOS 使用终端。
2. **找不到 Python**：运行 `python --version`、`python3 --version` 或 `py --version`；安装 Python 3.10+ 后重开终端。
3. **Windows 报 `No module named _curses`**：运行 `py -3 -m pip install -r requirements-windows.txt`，与启动脚本保持相同解释器。
4. **找不到 `ffplay`**：运行 `ffplay -version`；检查 PATH、重开终端，或把 FFmpeg 的 `bin` 目录加入 PATH。若构建不含 `ffplay.exe`，从 FFmpeg 官方下载页选择完整构建。
5. **中文或空格路径启动失败**：使用上文带引号的 `cd`/`Set-Location` 示例。确认 ZIP 解压后 `launcher.py` 位于当前目录。
6. **终端显示异常或无法交互**：在真正的交互式终端运行，不要通过管道启动；把终端窗口扩大后重试。
7. **学习记录看起来不是自己的**：退出程序，确认当前启动是否带了 `--portable`，并检查对应的 `user-data/` 或系统用户目录。发给朋友应重新使用清洁 ZIP。
8. **提醒没有出现**：Linux 检查 `systemctl --user status ielts-cli-portable-review.timer` 和 `notify-send` 是否存在；确认用户处于登录会话、已有到期词且没有暂缓提醒。Windows/macOS 后台命令不适用。
