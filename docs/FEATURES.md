# 功能说明

IELTS CLI 适合普通终端、Agent Desktop 的 CLI 窗口，以及开发或学习间隙的短时练习。程序是本地 curses CLI，不提供网页、后台服务、IPC 或模型 API。

## 学习流程

V3 默认每日任务包含新词和到期复习。新词混合安排四种基础模式：跟打 `copy`、英选中 `en_to_zh`、中选英 `zh_to_en`、默写 `recall`。跟打用于熟悉拼写，不单独表示已经记住；各题型成绩分别记录。

中选英和默写显示词条 `trans` 中的全部中文释义。小终端中长释义会分页；至少需要 40 列、6 行。精确字符串判分，大小写和空白按程序规则处理；同义词不会自动视为正确。

每日任务完成后，V3 默认进入增量例句与搭配练习。当前材料仅覆盖 124 个词。增量练习独立统计，不抬高正常新词/复习目标，也不会因答对而连续推远原复习间隔。学习过程中穿插例句默认关闭，可从 Esc 菜单的学习计划开启。

## 快捷键与菜单

F7/Ctrl+D 选择词库，F8/Ctrl+K 选择章节，F9/Ctrl+B 进入或暂停复习，F11/Ctrl+Y 查看今日任务，F5/Ctrl+P 播放当前词，F6/Ctrl+T 切换自动发音。Esc 打开菜单；若 Agent Desktop 宿主拦截 F10，使用 Esc 或空输入时的 `?`。

## 发音与提醒

发音调用 PATH 中的 `ffplay`。第一次请求某个词会从有道发音服务取音频并缓存，文字题可离线继续。程序内提醒可配置；退出后的 systemd user timer 仅在 Linux 可用。

## 进度隔离

每个应用版本和词库各自保存进度。切换词库会创建或恢复对应 profile，旧 profile 不会与新词库自动合并；版本迁移是一次性复制。便携模式使用 `user-data/`，适合把整个目录带到另一台机器。
