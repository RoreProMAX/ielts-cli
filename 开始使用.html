IELTS CLI 通用分享包

默认运行 V3.2；包内也保留 V1、V2。五本英语/雅思词库随包提供。

学习会自动穿插跟打、英选中、中选英和默写，完成一组后继续下一组。Esc 打开菜单（输入为空时也可按 ?），选 3 可手动指定题型。

  1. 解压整个 ZIP 到一个可写的文件夹。
  2. 安装 Python 3.10+。Windows 还需在本文件夹执行 py -3 -m pip install -r requirements-windows.txt。
  3. Windows 双击 start.bat；macOS 双击 start.command；Linux 在终端运行 sh start.sh。

首次安装和发音配置请打开 [部署指南](docs/部署指南.html)；学习操作见 [使用手册](docs/使用手册.html)。

在终端执行以下命令可检查环境和文件：

Windows:     start.bat --doctor --verify
Linux/macOS: sh start.sh --doctor --verify

默认进度保存在当前电脑的用户目录。加 --portable 后，进度与音频缓存保存在本文件夹的 user-data/，退出程序后可连同文件夹一起带走。切换版本使用 --app-version 1、2 或 3。

发给朋友时直接发送原始 ZIP。它不含发布者的学习记录、账号、音频缓存或系统配置。

文字练习可离线使用。读音需要 ffplay；首次获取某个词的音频需要联网，缓存后可离线重播。Python、Windows curses 组件和 FFmpeg 需要另外安装。

本包按 Windows、macOS、Linux 适配；已完成的平台验证结果见 VERIFICATION.json。Windows 和 macOS 尚未进行真机验收。Linux 可选后台提醒，其它平台使用程序内提醒。

中选英和默写展示词库已有的完整释义。小窗口中可用上下键或 PageUp/PageDown 翻阅长释义。

每日基础任务完成后默认进入增量例句与搭配练习；Esc 菜单的学习计划可开启“学习过程中加入例句”。已有 124 词的配套材料。
